# Agent instructions for this project

Load and apply the audit-report skill (.agents/skills/audit-report/SKILL.md) 
for any task involving verification, auditing, testing, or reporting 
on code state — proactively, without being asked to use it by name.

Within that same skill file, apply the Gap Verification section for 
any task involving a claim you did not personally verify — a status 
reported by another tool, a prior conclusion being repeated, an 
explanation that sounds complete but hasn't been checked against an 
independent source. Apply it especially when: re-stating something 
concluded earlier in the session, evaluating whether something is 
"done" or "safe," or when a plausible explanation is available but no 
command/output backs it yet.

General principle: when a request is underspecified, infer the most 
reasonable intent from project context and act on it rather than 
asking for clarification upfront, but always state your inferred 
interpretation in one sentence before proceeding.
